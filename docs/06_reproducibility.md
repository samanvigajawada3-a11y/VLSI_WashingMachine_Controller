# Reproducibility

Simulation can be rerun with Icarus Verilog. Generic synthesis can be rerun with Yosys. Recreating physical-design artifacts requires a compatible OpenROAD-flow-scripts checkout, the SKY130 HD PDK/platform files, and compatible tool versions.

The project contains retained run outputs so that the result can be inspected even when the original environment is unavailable. The presence of GDS/DEF/ODB files alone does not constitute foundry sign-off.
