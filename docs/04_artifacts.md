# Artifact guide

- `rtl/washing_machine_controller.v`: source RTL.
- `tb/tb_washing_machine_controller.v`: testbench.
- `tb/washing_machine.vcd` and `sim/washing_machine.vcd`: waveform captures.
- `synth/washing_machine_synth.v`: retained synthesized netlist.
- `gds/6_final.gds`: final GDS output.
- `gds/6_1_merged.gds`: merged GDS output.
- `physical_design/6_final.def`, `6_final.odb`, `6_final.sdc`, `6_final.spef`, `6_final.v`: final implementation outputs.
- `report/6_finish.rpt`: final-stage report.
- `logs/`: synthesis and OpenROAD stage logs/JSON summaries.
- `screenshots/`: visual captures of implementation stages.
